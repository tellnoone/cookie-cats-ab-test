==========================================================================
SIMULATION: CUPED VARIANCE REDUCTION  (simulated -- NOT Cookie Cats)
==========================================================================

  **********************************************************************
  *  Every number below is generated in this script.                     *
  *  The Cookie Cats snapshot has NO pre-experiment period, so CUPED     *
  *  cannot be applied to it. Using sum_gamerounds as the covariate      *
  *  would be invalid: it is measured during the experiment and is       *
  *  affected by the treatment.                                          *
  **********************************************************************

  Simulations    : 2,000
  Users per arm  : 10,000
  True effect    : +1.0 pp

==========================================================================
1. THE SETUP
==========================================================================

  Each simulated user has a latent engagement level u ~ N(0, 1).

    pre-period covariate  X = Poisson(exp(2.2 + 1.1u))
        -- e.g. rounds played in the week BEFORE the experiment started
    outcome               Y = Bernoulli(sigmoid(-2.3 + 2.0u) + effect)

  u drives both, so X predicts Y without being caused by the treatment.
  That is exactly the property CUPED needs, and exactly the property
  sum_gamerounds lacks in the real dataset.

  Correlation between X and Y : rho = 0.4846
  Theoretical variance reduction = rho^2 = 0.2349  (23.5%)
  Baseline outcome rate       : 19.20%

  CUPED's variance reduction is rho^2 and nothing else. That single fact is
  the most useful thing to know about it -- the payoff is quadratic, so a
  mediocre covariate is nearly worthless and a strong one is transformative.

  Covariate strength sweep (theoretical, from rho^2):

       rho   var reduction    n needed                   verdict
       0.1           1.0%        99%    not worth the pipeline
       0.2           4.0%        96%                  marginal
       0.3           9.0%        91%                    modest
       0.5          25.0%        75%                worthwhile
       0.7          49.0%        51%                     large
       0.9          81.0%        19%            transformative

  This simulation's covariate sits at rho = 0.48, so it is in the
  'worthwhile' band -- a realistic figure for a pre-period engagement
  metric predicting retention.

==========================================================================
2. PLAIN vs CUPED, over many simulated experiments
==========================================================================

                                     plain         CUPED
  mean estimate (pp)                0.9967        0.9999
  true effect (pp)                  1.0000        1.0000
  bias (pp)                        -0.0033       -0.0001
  SD of estimates (pp)              0.5772        0.5002
  mean analytic SE (pp)             0.5631        0.4957

  Both are unbiased -- CUPED reduces variance WITHOUT moving the estimate.
  That is the property that makes it legitimate rather than a thumb on the
  scale. It removes variance that the covariate could have predicted anyway.

  Observed variance reduction : 24.89%
  Predicted (rho^2)           : 23.49%
  SE reduction                : 11.96%

==========================================================================
3. WHAT THE VARIANCE REDUCTION BUYS
==========================================================================

  Required n scales with the variance of the estimator, so cutting
  variance by 24.9% cuts the required sample by the same factor.

  To detect 1.0pp at 80% power, alpha = 0.05:
    plain  :    24,352 users per arm
    CUPED  :    18,292 users per arm
    saving :     6,060 users per arm (24.9%)

  Equivalently, at a fixed sample size the experiment finishes sooner, or
  detects a smaller effect for the same duration.

  Power at the simulated n = 10,000 per arm:
    plain : 42.05%
    CUPED : 52.25%

  Sanity check -- type I error under a TRUE NULL (effect = 0):
    plain : 3.83%   (target 5%)
    CUPED : 4.00%   (target 5%)

  CUPED buys power without inflating the false-positive rate. It is a
  variance-reduction technique, not a significance-manufacturing one.

==========================================================================
4. WHY THIS IS NOT APPLIED TO THE REAL DATA
==========================================================================

  The temptation with the Cookie Cats snapshot is to use sum_gamerounds as
  the covariate, since it is strongly correlated with retention. That would
  be wrong. CUPED requires the covariate to be measured BEFORE treatment
  assignment. sum_gamerounds is measured during the experiment, and the
  gate directly changes it -- section 5B of the segment analysis shows the
  treatment shifting users between rounds buckets (chi2 p = 0.0001).

  Adjusting for a treatment-affected covariate does not de-noise the
  estimate; it removes part of the causal effect being measured. The
  honest position is that this dataset does not support CUPED, which is
  why section 7 of the plan put it here with simulated data.
