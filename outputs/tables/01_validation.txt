4. COVARIATE BALANCE
==========================================================================

  Stated plainly: this dataset has NO true pre-treatment covariates. There is
  no country, device, install date, or acquisition channel. `sum_gamerounds`
  and both retention flags are measured after the gate takes effect, so none
  of them can be used to establish that the arms started comparable.

  The one treatment-independent field is `userid`. If ids are issued in
  install order -- the usual case -- then its distribution is a weak proxy for
  when a player joined, and an imbalance would suggest the arms were drawn
  from different time windows or id ranges.

                               gate_30       gate_40
  userid min                       116           377
  userid 25th pct            2,505,469     2,517,171
  userid median              4,983,631     5,007,329
  userid 75th pct            7,481,497     7,510,762
  userid max                 9,999,710     9,999,861
  userid mean                4,987,564     5,009,073

  KS test on userid distribution : D = 0.00615, p = 0.3604
  Mann-Whitney U on userid       : p = 0.2609

  No detectable imbalance on the only treatment-independent field available.
  This is weak reassurance, not covariate balance in the usual sense.
